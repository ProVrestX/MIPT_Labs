\chapter{Выводы} \vspace{-20pt}
\label{ch:conclusions}

В результате было показано, что методы геометрической оптики могут быть использованы для точного определения фокусных расстояний линз и расчёта увеличений оптических приборов. 

Экспериментальные измерения фокусного расстояния линзы 2 методом Бесселя дали среднее значение $f_{2\text{Б}_\text{ср}} = (148,9 \pm 0,6)$ мм, что совпало с оцененным значением $f_{2} = (149,0 \pm 1,0)$ мм в пределах погрешности. Это подтвердило высокую точность метода Бесселя, не требующего знания положения главных плоскостей линзы. Метод Аббе для линзы 1 дал результат $f_{1\text{А}} = (69 \pm 5)$ мм, схожий с оценочным значением $f_{1} = (73,0 \pm 1,0)$ мм, однако с большей относительной погрешностью, что связано с трудностями точного измерения размеров изображений.

При сборке модели телескопа Кеплера измеренное угловое увеличение $\gamma_{\text{эксп}} = (2,03 \pm 0,06)$ совпало с теоретическим расчётом $\gamma_{\text{теор}} = (2,04 \pm 0,03)$ в пределах погрешности. Для метода измерения по диаметрам зрачков $\gamma_D = (2,10 \pm 0,08)$ также оказалось схожим с теоретическим значением.

Для модели микроскопа с расчётным увеличением $\gamma \approx 4$ экспериментальное значение $\gamma_{\infty} = (4,1 \pm 0,3)$ согласовалось с теорией, что подтвердило применимость формул для реальных оптических схем.

\chapter{Выводы} \vspace{-20pt}
\label{ch:conclusions}

% В результате было показано, что исследование эффекта Поккельса в кристалле ниобата лития может быть использовано для определения собственного двулучепреломления кристалла и полуволнового напряжения, характеризующего эффективность электрооптической модуляции.

Экспериментальное изучение коноскопической интерференционной картины позволило определить разность показателей преломления $(0,087 \pm 0,004)$. Полученное значение совпало в пределах погрешности с табличным $0,09$, что подтвердило применимость метода интерференции рассеянного света для определения оптических параметров анизотропных кристаллов.

При подаче постоянного напряжения на кристалл было получено полуволновое напряжение $465$~В, при котором интенсивность прошедшего света достигала максимума для скрещенных поляризаций. Значение $225$~В соответствовало получению круговой поляризации, что проверялось вращением анализатора: интенсивность не зависела от его ориентации.

Определение полуволнового напряжения по фигурам Лиссажу дало значение $465$~В, полностью совпадающее с результатом измерений при постоянном напряжении. Небольшое расхождение значений напряжения полной волны ($930$~В для постоянного и $885$~В для переменного напряжения) может быть связано с нелинейностью осциллографа и погрешностью визуального определения экстремумов на фигуре Лиссажу.

Полученные результаты подтвердили применимость эффекта Поккельса для управления поляризацией света и возможность использования кристалла ниобата лития в качестве электрооптического модулятора в лазерной технике и системах оптической связи.

\chapter{Результаты}
\label{ch:results}

Для определения необходимых зависимостей была использована установка, представляющая собой колебательный контур, состоящий из катушки индуктивности, конденсатора переменной емкости и переменного резистора, а также генератора сигналов и осциллографа. Полное описание установки см. в Приложении.

В результате была получена зависимость периода колебаний контура от емкости конденсатора в нем, изменяющейся в диапазоне от 25 до 50 нФ. Полученное отношение представлено на рис. \ref{fig:T_C}.

\FloatBarrier

Из графика видно, что полученное отношение находится немного выше теоретически рассчитанного с помощью \eqref{equ:T_C}. Из этого был сделан вывод, что в контуре присутствует небольшое сопротивление или дополнительная емкость.

Далее была определена зависимость декремента затухания от дополнительного сопротивления в контуре. Измерения проведены для сопротивлений в диапазоне от 140 до 650 Ом и представлены в координатах $\frac{1}{\eta^2}$ vs $\frac{1}{R^2}$ на рис. \ref{fig:eta_R}.

\begin{figure}[ht]
	\begin{gnuplot}[terminal = pdf]
		set table "tmp/eta_R_tmp.txt"
		plot "txt/eta_R.txt" u (1/($1**2)):(1/($2**2))
		unset table
		
		f(x) = k*x + b
		fit f(x) "tmp/eta_R_tmp.txt" u 1:2 via k,b
		
		set print "tmp/eta_R_fit_tmp.txt"
		print sprintf("k= %f ± %f", k, k_err)
		print sprintf("b= %f ± %f", b, b_err)
		set print
		
		set xl "1/R^2, ×10^{-5} 1/Ом^2"
		set format x "%.1f"
		set yl "1/Θ^2"
		set format y "%.1f"
		set grid
		unset key
		
		plot "txt/eta_R.txt" u (1/($1**2)*(10**5)):(1/($2**2)):(1/($1**2)*(10**5)*($3/$1)):(1/($2**2)*($4/$2)) w xye pt 0, f(x)*(10**(-5)) + b lw 2 lc "red"
		
	\end{gnuplot}
	\vspace{-40pt}
	\caption{Зависимость декремента затухания от сопротивления в контуре.}
	\label{fig:eta_R}
\end{figure}
\FloatBarrier

Из графика видно линейный вид полученного зависимости. Это означает, что коэффициент отношения постоянен и его можно найти. С помощью МНК было получено, что он равен $2261.4 \pm 35.5$. Добротность составила $6.98 \pm 0.16$ для 141 Ом и $1.904 \pm 0.044$ для 649 Ом.

Также были получены АЧХ и ФЧХ колебательного контура. Для этого экспериментально определены зависимости амплитуд напряжения на конденсаторе и разности фаз от частоты генератора, представленные на рис. \ref{fig:U_nu} и \ref{fig:dphi_nu} соответственно.

Из графика \ref{fig:U_nu} было определено, что разница частот в точках, когда отношение напряжения к амплитудному напряжению равно $0.7$, составила $\Delta \nu/\nu_0 = 0.1560 \pm 0.004$ для 141 Ом и $\Delta \nu/\nu_0 = 0.602 \pm 0.014$ для 649 Ом. Добротность составила $6.41 \pm 0.15$ для 141 Ом и $1.661 \pm 0.038$ для 649 Ом.

Добротность составила $7.937 \pm 0.19$ для 141 Ом и $1.992 \pm 0.046$ для 649 Ом.

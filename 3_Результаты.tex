\chapter{Результаты} \vspace{-20pt}
\label{ch:results}

Для выполнения работы использовалась оптическая скамья с набором компонентов на регулируемых рейтерах: источник света на базе трёхцветного светодиода с регулировкой интенсивности, входная оптическая щель с микрометрическим винтом, собирающие линзы, исследуемые препятствия (одинарная и двойная щели, линейное препятствие, круглые отверстия и диски). Регистрация дифракционных картин осуществлялась тринокулярным микроскопом с видеокамерой. Все измерения выполнялись после предварительной юстировки оптической оси и установки диафрагмы для уменьшения аберраций и повышения контрастности картины. Использованные в работе оптические схемы приведены в Приложении.

В результате измерений была получена зависимость расстояния $z$ от щели до плоскости наблюдения от числа $m$ видимых тёмных дифракционных полос. Данные значения представлены на рис. \ref{fig:z_m_fren}.

\begin{figure}[ht]
    \begin{gnuplot}[terminal=pdf]
        set xl "1/m, номер зоны^{-1}"
        set xr [0:1.1]
        set format x "%.1f"
        set xtics 0.1

        set yl "z, мм"

        unset key
        set grid

        n(x) = k*x + b
        fit n(x) "txt/x(n)_dif_fren.txt" u (1/$1):2 via k,b

        plot "txt/x(n)_dif_fren.txt" u (1/$1):2:3 w ye lw 1 pt 0, n(x)
    \end{gnuplot}
    \vspace{-30pt}
    \caption{Расстояние $z$ от щели до плоскости наблюдения в зависимости от количества $m$ видимых темных полос.}
    \vspace{-10pt}
    \label{fig:z_m_fren}
\end{figure}
\FloatBarrier

По графику было определено, что зависимость $z(\frac{1}{m})$ имеет линейный вид, что согласуется с теоретическим соотношением \eqref{equ:fresnel_sym}. С помощью метода наименьших квадратов был определён наклон прямой, по которому рассчитана ширина $b = (0,389 \pm 0,015)$ мм щели. Это значение совпадало в пределах погрешности с $b_\text{изм} = (0,392 \pm 0,006)$ мм, полученным непосредственным измерением по показаниям микрометрического винта. Результат подтвердил применимость метода зон Френеля для определения геометрических параметров препятствий.

Для дифракции в дальней зоне были измерены координаты $x$ минимумов интенсивности полученной интерференционной картины в зависимости от их номера $n$. Результаты представлены на рис. \ref{fig:z_m_fraun}.

\begin{figure}[ht]
    \begin{gnuplot}[terminal=pdf]
        set xl "n, номер экстремума"
        set xtics 1

        set yl "x, мкм"

        unset key
        set grid

        f(x) = k*x + b
        fit f(x) "txt/x(n)_dif_fraun.txt" u 1:($2/892*1000) via k,b

        plot "txt/x(n)_dif_fraun.txt" u 1:($2/892*1000):(10/892*1000) w ye lw 1 pt 0, f(x)
    \end{gnuplot}
    \vspace{-30pt}
    \caption{Отклонение $x$ положения минимума интерференции от центра экрана в зависимости от его номера $n$.}
    \vspace{-10pt}
    \label{fig:z_m_fraun}
\end{figure}
\FloatBarrier

Благодоря графику был сделан вывод о возможности аппроксимации зависимости $x(n)$ прямой линией, что соответствует теоретической формуле \eqref{equ:fraunhofer_coords}. По наклону графика была определена ширина щели $b = (1,24 \pm 0,11)$ мм, что согласуется с прямым измерением $b_\text{изм} = (1,278 \pm 0,027)$ мм. Небольшое расхождение результатов может объясниться аберрациями оптической системы.

При наблюдении интерференционной картины от двух щелей были измерены расстояние $\delta x$ между соседними минимумами и количество $N$ этих минимумов. с помощью полученных значений были определены по \eqref{equ:fringe_spacing} расстояние $d = (0,90 \pm 0,08)$ мм между щелями и по \eqref{equ:num_fringes} ширина $b = 0,200 \pm 0,016$ мм самих щелей. Эти значения совпали в пределах погрешности с результатами прямого измерения микроскопом: $d_\text{изм} = (0,952 \pm 0,004)$ мм и $b_\text{изм} = (0,1906 \pm 0,0022)$ мм. Результат показал применимость формул дифракции Фраунгофера для бесконтактного определения геометрических параметров щелей.

Также была проверена необходимость выполнения условия когерентности \eqref{equ:coherence}. Наблюдаемая картина была четкой при соблюдении данного условия и становилась размытой при его нарушении, что подтвердило когерентный характер интерференции волн от двух щелей.

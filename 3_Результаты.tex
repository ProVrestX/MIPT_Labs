\chapter{Результаты}
\label{ch:results}

Для определения необходимых зависимостей была использована установка, состоящая из генератора сигналов и осциллографа. Также был использован RC-элемент, представляющий из себя RC-фильтр низких частот. Полное описание установки см. в Приложении.

В результате были получены зависимости параметров преобразования Фурье для прямоугольного сигнала, такие как ширина $\Delta \nu$ от пиковой гармоники до нулевой и ширина $\delta \nu$ между гармониками, от длительности импульса $\tau$ сигнала и периода его повторения $T$. Полученные зависимости представлены на рис. \ref{fig:nu_t}.

\begin{figure}[ht]
    \begin{subfigure}{0.48\textwidth} 
        \begin{gnuplot}[terminal=pdf]
            set xl "1/τ, мс^{-1}"
            set xr [0:55]
            set xtics 5

            set yl "∆ν, кГц"
            set yr [0:55]

            set grid
            unset key

            plot "txt/Dv_t.txt" u (1/($1*10**(-3))):2 w lp lw 2 ps 0.5 pt 7
        \end{gnuplot}
        \vspace{-20pt}
        \caption{Зависимость $\Delta \nu$ от обратной длительности импульса $1/\tau$.}
    \end{subfigure}
    \begin{subfigure}{0.48\textwidth} 
        \begin{gnuplot}[terminal=pdf]
            set xl "1/T, мс^{-1}"
            set xr [0:5.5]
            set xtics 0.5
            
            set yl "δν, кГц"
            set yr [0:5.5]
            
            set grid
            unset key

            plot "txt/dv_T.txt" u (1/$1):2 w lp lw 2 ps 0.5 pt 7
        \end{gnuplot}
        \vspace{-20pt}
        \caption{Зависимость $\delta \nu$ от частоты повторения импульса $1/T$.}
    \end{subfigure}
    \caption{Изменения спектра Фурье от входного сигнала прямоугольной формы.}
    \label{fig:nu_t}
\end{figure}
\FloatBarrier

Из графиков видно, что параметры $\Delta \nu$ и $\delta \nu$ линейно зависимы от $1/\tau$ и $1/T$. Из этого был сделан вывод об их обратной пропорциональности к $\tau$ и $T$ соответственно, что подтвердило теорию соотношения неопределенностей.

Далее были получены зависимости амплитуд основной и боковых гармоник от глубины модуляции модулированного по амплитуде синусоидального сигнала. Изменения отношения амплитуд $a_\text{бок}/a_\text{осн}$ от глубины модуляции $m$ представлены на рис. \ref{fig:a_m}.

\begin{figure}[ht]
    \begin{gnuplot}[terminal=pdf]
        set xl "m, %"
        set xr [0:110]
        set xtics 10

        set yl "a_{бок}/a_{осн}"
        set yr [0:0.5]
        set ytics 0.05
        set format y "%.2f"

        set grid
        set key b

        plot "txt/a_m.txt" u 1:($1/100/2) w l lw 2 t "Теор", "txt/a_m.txt" u 1:2:3:4 w xye pt 0 t "Эксп"
    \end{gnuplot}
    \vspace{-20pt}
    \caption{Зависимость отношения амплитуд боковой и основной спектральных линий $a_\text{бок}/a_\text{осн}$ от глубины модуляции $m$.}
    \label{fig:a_m}
\end{figure}
\FloatBarrier

По графику видно, что полученные значения сходится с теоретическими $a_\text{бок}/a_\text{осн} = \frac{m}{2}$. Это означает, что амплитудно-модулированное колебание представляется в виде суммы трёх гармонических колебаний (трёх гармоник).

Также было получено отношение амплитуд $a_\text{ф}$ и $a_\text{и}$ гармоник фильтрованного сигнала и исходного соответственно для цепи с RC-элементом. Зависимость коэффициента фильтрации $K = \frac{a_\text{ф}}{a_\text{и}}$ от частоты гармоники $\nu = n \nu_0$ представлена на рис. \ref{fig:a_nu}.

\begin{figure}[ht]
    \begin{gnuplot}[terminal=pdf]
        set xl "1/ν, МГц^{-1}"
        set xr [0:3.5]
        set xtics 0.5
        set format x "%.1f"

        set yl "K = a_{ф}/a_{и}"
        set yr [0:0.17]
        set ytics 0.02
        set format y "%.2f"

        set grid
        unset key

        plot "txt/K_n.txt" u (1/($1*300)*(10**3)):2 w lp lw 2 ps 0.5 pt 7
    \end{gnuplot}
    \vspace{-20pt}
    \caption{Зависимость коэффициента фильтрации $K = \frac{a_\text{ф}}{a_\text{и}}$ от обратной частоты $1/\nu = \frac{1}{n \nu_0}$.}
    \label{fig:a_nu}
\end{figure}
\FloatBarrier

Из графика видно линейный вид зависимости коэффициента фильтрации $K$ от обратной частоты $1/\nu$. Из этого было получено, что он прямо пропорционален периоду $T = 1/\nu$. Данный вывод соответствует модели низкочастотного фильтра $1/\sqrt{1 + (2\pi\nu RC)^2}$.

\chapter{Результаты}
\label{ch:results}


Для определения необходимых зависимостей была использована установка, состоящая из источников высокого и назкого напряжения, вольт- и амперметров, а также газоразрядной трубки с зондами. Полное описание установки см. в Приложении.

В результате была получена зависимость силы тока, проходящей через газоразрядную трубку, от напряжения на ней в диапазоне от 170 до 350 В. Полученное отношение представлено на рис. \ref{fig:I_Uh}.

\begin{figure}[ht]
    \begin{gnuplot}[terminal=pdf]
        set xl "U, В"

        set yl "I, мА"
        set yr [0:4.5]
        set format y "%.1f"

        unset key
        set grid

        f(x) = k*x + b
        fit f(x) "txt/I_Uh.txt" u 1:2 via k,b

        set style line 1 pt 7 ps 0.5 lw 2
        plot "txt/I_Uh.txt" u 1:2:3:4 w xye pt 0, f(x) ls 1
    \end{gnuplot}
    \vspace{-30pt}
    \caption{Зависимость силы тока разряда от его напряжения.}
    \label{fig:I_Uh}
\end{figure}
\FloatBarrier

По графику виднен линейный вид полученной зависимости. Из этого был сделан вывод, что коэффициент отношения постоянен и его можно найти. С помощью полученного значения было определено дифференциальное сопротивление разряда $R_\text{диф} = (52.6 \pm 2.8)$ кОм

% $k = -0.019 \pm 0.001$ \\
% $R = (52.6 \pm 2.8)$ кОм

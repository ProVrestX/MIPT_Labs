\chapter{Результаты} \vspace{-20pt}
\label{ch:results}

Для измерения необходимых зависимостей использовалась оптическая схема с гелий-неоновым лазером ($\lambda = 630$~нм), кристаллом ниобата лития ($\text{LiNbO}_3$), поляризационными элементами и устройствами для регистрации интерференционной картины (экран и фотодиод с осциллографом). Все измерения проводились после предварительной юстировки оптической оси и настройки скрещенных поляризаций для достижения минимального пропускания системы. Использованные в работе оптические схемы приведены в Приложении.

В результате измерений были получены радиусы $r_m$ тёмных колец в зависимости от их порядкового номера $m$ при наблюдении коноскопической картины. Зависимость квадрата радиуса кольца от его номера представлена на рис.~\ref{fig:z_m_fren}.

По графику было определено, что зависимость $r^2(m)$ имеет линейный вид, что согласуется с теоретической формулой~\eqref{eq:ring_radius}. С помощью метода наименьших квадратов был определён наклон прямой, по которому рассчитано двулучепреломление кристалла ниобата лития $(n_o - n_e) = (0,087 \pm 0,004)$. Полученное значение совпало в пределах погрешности с табличным$^\text{\cite{Lab}}$ $(n_o - n_e)_\text{таб} = 0,09$. Это подтвердило применимость метода интерференции рассеянного света для бесконтактного определения оптических параметров анизотропных кристаллов.

Далее были проведены измерения полуволнового напряжения при подаче на кристалл постоянного напряжения с помощью наблюдения изменения вращением анализатора интенсивности прошедшего света. При напряжении $U = 225$~В интенсивность не зависела от ориентации анализатора, что соответствует круговой поляризации и напряжению $U_{\lambda/4}$. При дальнейшем увеличении напряжения интенсивность достигала максимума при $U_{\lambda/2} = 465$~В и снова становилась минимальной при $U_{\lambda} = 930$~В.

Также было проведено определение напряжений по фигурам Лиссажу на экране осциллографа при подаче переменного напряжения. Наблюдались характерные зависимости интенсивности от напряжения для скрещенных поляризаций. По переходу от максимума к минимуму интенсивности были определены следующие значения:
\[
    U_{\lambda/2} = 465~\text{В}, \quad U_{\lambda} = 885~\text{В}, \quad U_{3\lambda/2} = 1320~\text{В}.
\]

Сравнение значений полуволнового напряжения, полученных при постоянном и переменном напряжении, показало их схождение. Значение $U_{\lambda/2} = 465$~В совпало для обоих методов, что подтвердило корректность проведённых измерений. Небольшое расхождение для $U_{\lambda}$ ($930$~В для постоянного и $885$~В для переменного напряжения) может быть связано с нелинейностью осциллографа и погрешностью определения положения экстремумов на фигуре Лиссажу.

Результаты работы подтвердили применимость эффекта Поккельса для управления поляризацией света и возможность использования кристалла ниобата лития в качестве электрооптического модулятора.

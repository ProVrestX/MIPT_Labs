\chapter{Результаты}
\label{ch:results}

Для определения необходимых зависимостей была использована установка, состоящая из электромагнита и источника питания для него, образца для исследования и блока управления для него, а также вольтметра и милливеберметра. Полное описание установки см. в Приложении.

Для определения текущей индукции магнитного поля электромагнита была исследована его зависимость от тока через обмотки с помощью милливеберметра. Подробную методику определения см. в Приложении.

В результате были получены зависимости поперечного ЭДС Холла от магнитного поля в пределах от 0.1 до 1.2 Тл для 6 различных токов через образец. Полученные отношения представлены на рис. \ref{fig:V(B)}.

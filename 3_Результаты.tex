\chapter{Результаты} \vspace{-20pt}
\label{ch:results}

Для выполнения работы использовалась оптическая скамья с набором линз на регулируемых креплениях, источником света с транспарантом, экраном и вспомогательной подзорной трубой, настроенной на бесконечность. Все измерения проводились после предварительной центровки оптической оси и установки диафрагмы 5 мм для уменьшения аберраций. Использованные в работе оптические схемы см. в Приложении.

В начале были оценены фокусные расстояния собирающих и рассеивающей линз методом наведения на удалённый источник. Результаты измерений представлены в таблице \ref{tab:f_telescope}.

Для линзы 2 было проведено сравнение способов определения фокуса: формула тонкой линзы и метод Бесселя. При фиксированном расстоянии между предметом и экраном были найдены два положения линзы, дающие чёткие изображения. По результатам измерений (см. в Приложении) с помощью \eqref{equ:bessel} были расчитаны фокусные расстояния для прямой и обратной ориентации линзы: $f_{2\text{Б}_\text{п}} = (149,5 \pm 0,4)$ мм и $f_{2\text{Б}_\text{о}} = (148,3 \pm 0,4)$ мм соответственно. Полученные значения совпали в пределах погрешности с оцененным ранее значением $f_{2} = (149,0 \pm 1,0)$ мм. 
Незначительное расхождение результатов при развороте линзы подтвердило, что ее можно считать тонкой в данной работе.

Затем для линзы 1 было определено фокусное расстояние с помощью метода Аббе. Для предмета определенного размера были получены 2 изображения разного размера при смещении предмета на заданное расстояние. С помощью измеренных значений (см. в Приложении) по \eqref{equ:abbe} было определено фокусное расстояние $f_{1\text{А}} = (69 \pm 4)$ мм.
Погрешность метода Аббе оказалась выше, чем у метода Бесселя, что связано с трудностями точного измерения размеров изображений и малым числом повторений.

Далее была собрана модель телескопа Кеплера с объективом из линзы 2 и окуляром из линзы 1. Угловое увеличение измерялось двумя способами: по уловым размерам и по диаметрам ``зрачков''.
Для первого способа с помощью вспомогательной подзорной трубы сравнивались угловые размеры ячейки сетки через коллиматор и через телескоп. По полученным значениям было рассчитано угловое увеличение $\gamma_{\text{эксп}} = (2,03 \pm 0,06)$. 
Для измерения с помощью ``зрачков'' были определены диаметры входного и выходного пучков света. Для данного способа было получено угловое увеличение $\gamma_D = (2,10 \pm 0,08)$.
Теоретическое увеличение $\gamma_{\text{теор}} = (2,04 \pm 0,03)$, полученное из отношения фокусов линз, пересекается с обоими значениями в пределах погрешностей.

В конце была собрана модель микроскопа с объективом из линзы 1, окуляром из линзы 6 и расчитаным оптическим интервалом  для целевого увеличения $\gamma \approx 4$. Измерение проводилось в режиме аккомодации на бесконечность с использованием коллиматора из 4-й линзы и вспомогательной трубы.
При наблюдении через трубу было измерено увеличение микроскопа $\gamma_{\infty} = (4,1 \pm 0,3)$.
Результат совпал с теоретическим значением в пределах погрешности, что подтвердило применимость используемых формул.

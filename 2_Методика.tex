\chapter{Методика}
\label{ch:methods}

Узнать тип, концентрацию и подвижность носителей заряда в полупроводниках можно с помощью постоянной Холла. 

Концентрацию можно найти с помощью \cite{Lab}:
\begin{equation}\label{equ:R_H}
    n = -\dfrac{1}{R_H e}   
\end{equation}
где $n$ — концентрация носителей заряда, м⁻³; $R_H$ — постоянная Холла, м³/Кл;
$e = 1{,}60 \cdot 10^{-19}$ Кл — модуль заряда электрона.

По знаку постоянной Холла можно определить тип носителей заряда (знак «–» для n-типа проводимости, «+» - для p-типа).

Подвижность носителей можно вычислить с помощью \cite{Lab}:
\begin{equation}
    \mu = \rho_0 |R_H|,
    \label{eq:mu}
\end{equation}
где $\mu$~— подвижность носителей, м²/(В·с); $\rho_0$~— проводимость, (Ом·м); $R_H$ — постоянная Холла, м³/Кл.

В то время, как проводимость материала удобнее узнать, спроектировав такую установку, что при известрых параметрах изучаемого полупроводника, измерив силу тока и напряжение, ее (проводимость материала) можно вычислить по формуле \cite{Lab}:

\begin{equation}
    \rho_0 = \frac{U_{35} a d}{I l},
    \label{eq:rho0}
\end{equation}
где $\rho_0$~— проводимость материала, Ом·м; $U_{35}$~— падение напряжения между контактами 3 и 5, В; $a$~— ширина образца, м; $d$~— толщина образца, м; $I$~— сила тока через образец, А; $l$~— расстояние между контактами 3 и 5, м.
Описание установки смотри в Приложении.

Теперь разберемся, как найти постоянную Холла. Сделать это можно, измеренив разности потенциалов $\Delta E$ между холловскими контактами при 
фиксированном приращении магнитного поля $\Delta B$ \cite{Lab}:

\begin{equation}
    \Delta E = U_H = R_H \cdot \frac{I \cdot \Delta B}{d},
\end{equation}
где $U_H$ — напряжение Холла, $I$ — ток через образец, $\Delta B$ — приращение магнитного поля, $d$ — толщина образца.

Затем, если зависимости окажутся линейными, то нужно найти коэффициенты наклона К при фиксированных токах. Это можно сделать по формуле \cite{Lab}:
\begin{equation}
    K = \frac{\Delta E}{\Delta B} = \left( \frac{R_H}{d} \right) \cdot I.
\end{equation}

После этого нужно построив график K(I). Если зависимость также получается линейной, постоянную Холла можно найти при помощи \cite{Lab}:

\begin{equation}
    R_H = \frac{K d}{I}.
\end{equation}
где $R_H$ - постоянная Холла; $\frac{K}{I}$ - коэффициент наклона прямой; $d$ - толщина образца.

Теперь останется подставлять постоянную Холла в начальные формулы.

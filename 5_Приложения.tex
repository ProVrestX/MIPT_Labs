Для метода Аббе при размере предмета $y_0 = (1,000 \pm 0,010)$ см были получены размеры изображений $y_1 = (8,20 \pm 0,10)$ см и $y_2 = (2,40 \pm 0,10)$ см при смещении предмета $\Delta x = (20,0 \pm 1,0)$ см. Используя данные значения, было определено фокусное расстояние $f_{1\text{А}} = (69 \pm 4)$ мм для 1-й линзы.
